# איך פותחים את SAVIO 3.0?

האפליקציה אינה קובץ HTML שנפתח בלחיצה כפולה. היא יישום Next.js שצריך שרת, או אתר שנפרס ל־Vercel.

## הדרך הנוחה לטלפון

1. היכנסו לחשבון Vercel.
2. ייבאו את המאגר `Avioz549/Avioz`, ובחרו בענף `savio-3.0`.
3. השאירו את תיקיית הפרויקט בשורש ובחרו Next.js ו־Node 24.
4. לחצו Deploy. אין צורך ב־Supabase או במשתני סביבה לשימוש באפליקציה.
5. פתחו את כתובת האתר שקיבלתם. ב־iPhone אפשר לפתוח ב־Safari, ללחוץ שיתוף ואז ״הוספה למסך הבית״.

הנתונים נשמרים בדפדפן ובכתובת שבה משתמשים. לפני מעבר מכשיר, דפדפן, כתובת או מצב התקנה: ייצאו גיבוי JSON בהגדרות ושחזרו אותו במקום החדש. האחסון אינו קבוע ואינו מוצפן.

## פתיחה במחשב

התקינו Node.js 24, חלצו את ה־ZIP ופתחו מסוף בתיקייה שמכילה את `package.json`. הריצו:

```sh
npm ci
npm run dev
```

פתחו את הכתובת שהמסוף מציג, בדרך כלל `http://localhost:3000`. אין צורך בהרשמה או התחברות לאפליקציה.

## הנתונים הישנים שלי

נתונים מקומיים מגרסה 2 עוברים אוטומטית כשמשתמשים באותה כתובת. העותק הישן נשמר. אם הנתונים היו ב־Supabase, ייצאו JSON מהגרסה הישנה ושחזרו אותו דרך הגדרות → גיבוי ושחזור. גרסה 3 אינה מוחקת נתונים מהחשבון הישן.

שירות AI הוא אפשרות נפרדת. בלי מפתח שרת והגנת בקשות הוא מוצג כלא זמין, אבל התובנות המחושבות וכל כלי הניהול המקומיים עובדים.
